---
name: pr-workflow
description: Follow the MiniShop Issue-to-PR workflow for a repository change.
---

1. Confirm the Issue, tier, and scope.
2. Branch from updated `main` as `<type>/<issue>-<slug>`.
3. Make atomic, valid commits and record problems immediately.
4. Validate, then hand off to `doc-writer`; use `reviewer` for T2 or the pilot.
5. Rebase on `main`, open a Draft PR from the template, then stop. Never merge.
