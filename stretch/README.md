# Inactive stretch exercises

These exercises are deliberately not included in any active manifest or package.

- orders-endpoint.md: requires a rebuilt or patched backend image, which is outside the immutable-upstream core.
- network-policy.md: apply only after collecting the actual traffic and DNS requirements.
- vpa.md: install VPA separately and use recommendation-only mode.
- chaos.md: run only on a disposable cluster after recording a recovery plan.
